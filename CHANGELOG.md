# Changelog

## 1.1.0 (2026-10-05)

- Added explicit handling of two-beat negative fragments and "No X. No Y. Just Z.", including when the individual claims are concrete.
- Added specificity announcements such as "I want to be specific, because this is where people get stuck."
- Expanded examples for staged candor and generic introductions.
- Added a ranked reference for the 20 strongest giveaway phrases and patterns, with context and authorship caveats.
- Strengthened the final check for paraphrased patterns at sentence and paragraph level.
- Documented how students can refresh an existing installation.

## 1.0.0 (2026-09-04)

- Initial public release with edit, audit, and draft modes, a pattern library, an evaluation checklist, and Claude Code and Codex plugin packaging.
